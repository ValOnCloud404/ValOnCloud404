## ☁️ What is Microsoft Azure?

### 💜 Simple Definition

**Microsoft Azure** is a cloud computing platform.

It helps businesses:

- 💻 host applications  
- ☁️ store data  
- 🌍 run websites  
- 🔐 manage security  
- 🖥️ create virtual machines  
- 🤖 automate services

Think of Azure like:

> ☁️ **Renting computers and services from Microsoft over the internet**

Instead of buying physical servers, companies can build in the cloud.

---

## 🧠 Why Does Azure Matter?

Organizations use Azure to:

✅ reduce hardware costs  
✅ scale services quickly  
✅ improve security  
✅ backup data  
✅ host apps and websites  
✅ support remote work

Cloud skills are in high demand because most companies are moving away from on-premises infrastructure.

## ☁️ Azure Regions

### What is a Region?

A **Region** is a physical location where Azure data centers exist.

Example:

```txt
East US
West US
Central US
```

### Why It Matters

Regions help with:

- speed ⚡
- redundancy 🔄
- compliance 🔐

Think:

> “Where in the world is my cloud stuff located?”

---

## 💻 Virtual Machines (VMs)

### What is a VM?

A **Virtual Machine** is a computer running in Azure.

Instead of buying hardware:

You rent computing power in the cloud.

### Beginner Breakdown ☁️

Think:

> A laptop in the cloud that Microsoft manages for you.

---

## 🔐 RBAC (Role-Based Access Control)

### What is RBAC?

RBAC controls:

> **Who can do what in Azure**

Example:

| Role | Access |
|---|---|
| Reader | View only |
| Contributor | Make changes |
| Owner | Full access |
