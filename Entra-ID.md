<h2 align="center"><span style="color:#D946EF">🔑</span> Single Sign-On — One Login to Rule Them All</h2>

<p align="center"><sub>Remember having 14 different passwords for 14 different work apps? SSO says: never again.</sub></p>

**Single Sign-On (SSO)** lets users authenticate once and access every connected application without logging in again. You sign into your work account once in the morning — and that's it. Microsoft 365, Salesforce, Zoom, GitHub, Workday, ServiceNow — all open. No more password reset tickets at 9am.

```
👤 Employee logs in once → ✅ Entra ID verifies identity
                         → 🔑 Issues a token
                         → 📧 Opens Outlook
                         → 💬 Opens Teams
                         → 📊 Opens Salesforce
                         → 🗂️ Opens SharePoint
                         → ☁️ Opens Azure Portal
                            All without logging in again.
```

> 🎯 *For IT: fewer password reset tickets. For users: fewer reasons to write passwords on sticky notes. Win-win.*

<h2 align="center"><span style="color:#A21CAF">🛡️</span> Conditional Access — Smart Security Rules</h2>

<p align="center"><sub>Not a blanket "allow" or "deny" — it's "it depends," but automated and smart</sub></p>

**Conditional Access** is Entra ID's policy engine. It evaluates signals — who you are, where you're logging in from, what device you're on, what app you're accessing — and decides in real time whether to grant access, block it, or ask for more verification.

```
📍 Signal: Login from new country not seen before
📱 Signal: Unmanaged personal device
🕐 Signal: 3am login attempt (suspicious)
🔐 Signal: Trying to access payroll system

→ 🛡️ Conditional Access Policy fires:
   "MFA required + must be on compliant device"
   
✅ User has authenticator app + work laptop → ACCESS GRANTED
❌ User can't verify → ACCESS BLOCKED. Hacker goes home.
```

    ✅ SSO works for Salesforce, Workday, and DocuSign

No manual app setup. No separate credentials.
No "my email isn't working" ticket on day one.
Just vibes and productivity. 🔐☁️
