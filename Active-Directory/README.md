## ☁️ What Is Active Directory?

<div align="center">

| 🏫 Think of AD Like a Digital School Office |
|---|
| Instead of managing every computer separately, an admin manages **everything from one central place** — users, computers, passwords, permissions, and policies. |

</div>

**Active Directory (AD)** is Microsoft's directory service. It organizes and controls:

| Object | What It Is |
|--------|------------|
| 👤 **Users** | Employee accounts that need access to systems |
| 💻 **Computers** | Devices joined to the domain |
| 🏢 **Groups** | Collections of users or computers with shared permissions |
| 📁 **OUs (Organizational Units)** | Folders for organizing users and computers |
| 🔐 **GPOs (Group Policy Objects)** | Rules pushed to users/computers automatically |

---

## 🧠 Why Does Active Directory Matter?

Organizations use AD to do the heavy lifting of IT management at scale.

```
✅  Manage thousands of employee accounts from one place
✅  Reset passwords without touching individual machines
✅  Organize users by department, location, or role
✅  Apply security policies across the entire organization
✅  Control who has access to what files and systems
✅  Let employees sign in from any domain-joined computer
```
