## ☁️ What is Active Directory?

### 💜 Simple Definition

**Active Directory (AD)** is Microsoft’s directory service used to organize, manage, and control:

- 👤 Users  
- 💻 Computers  
- 🔐 Permissions  
- 🏢 Groups  
- 📁 Organizational Units (OUs)

Think of it like:

> 🏫 **A digital school office for computers and users**

Instead of managing every computer separately, administrators manage everything from one central place.

---

## 🧠 Why Does Active Directory Matter?

Organizations use Active Directory to:

✅ manage employee accounts  
✅ reset passwords  
✅ organize users and computers  
✅ apply security policies  
✅ control access to files and systems  
✅ allow users to sign in from different computers
